# 风见鸡 PWA 素材包

按上传的「已生成图像 1.png」原版轮廓描摹，未重新设计。SVG 是真正的闭合贝塞尔路径，无内嵌位图、字体或外部依赖。黑白版均为透明背景；母版保留原图 1254 × 1254 画布及轮廓位置。

## 文件
- svg/：黑、白透明 SVG 母版。
- icons/：黑白透明 PNG，各含 16、32、48、64、96、128、192、512 px。
- maskable/：独立 light / dark 两套 192、512 px，白底黑图 / 黑底白图，背景完全不透明。
- apple-touch-icon.png：默认白底黑图 180 × 180；apple/ 另有两种底色。
- favicon/：透明黑色 SVG；ICO 含 16、32、48、64、128、256 px。
- manifest.json、head-example.html：可修改的配置示例。
- reference/original.png：保留上传原图。
- verification/：轮廓比对预览、实际尺寸及安全区检查报告。

## 实测验证
以原图 alpha ≥ 128 的边界作为轮廓基准，SVG 用 resvg 渲染回 1254 × 1254 后比较：
- 交并比 IoU：99.6447%（两个实心轮廓重合程度）。
- 双向像素边缘平均距离：0.1210 px；95 分位 1.0 px；最大 1.0 px。
- 原图只有一个主体连通区域；保留为一个闭合路径。
- 尺寸、ICO 多尺寸条目、manifest 图标路径及 maskable 不透明背景均已逐项核验，详情见 report.json。

原图为有抗锯齿及轻微色彩/透明度变化的栅格图，单色矢量采用半透明阈值边界；这不是每一个 RGBA 像素都相等的复制。颜色被统一为纯黑或纯白，轮廓误差以上述实测为准。

## Maskable 安全区
依据 W3C，保证可见的安全区是以图标中心为圆心、半径为边长 40% 的圆。整只风见鸡（含箭头、尾部和下方圆球）等比缩放、平移至此圆内；本包预留至约 37.5% 半径，四个导出文件均通过像素检查。只改变在画布上的大小和位置，不改变内部比例。
规范：https://www.w3.org/TR/appmanifest/#icon-masks

## 接入
将素材包内容放到网站根目录，参考 head-example.html 引入。修改 manifest 的 name、short_name、id、start_url、scope 与主题色。当前示例按根路径应用配置；部署到子目录时，须同步修改 HTML 引用、manifest 图标路径和应用范围。
默认使用透明黑色普通图标和白底黑图 maskable；若应用使用深色背景，换成白色普通图标及 dark maskable，并调整 apple-touch-icon 引用。白色透明图标在白底上不可见。

## 你没问但应该知道的
小尺寸 favicon 仍保留原轮廓，尾羽和细杆在 16 px 时会受像素分辨率限制，没有擅自做简化版。maskable 为保证整只图案不被裁掉，视觉上比普通图标小。不同系统最终呈现仍需安装实测；本次完成的是文件、渲染及安全区验证。此素材包不包含 service worker（离线缓存脚本），单独放入这些文件不会自动使网站具备全部 PWA 能力。
